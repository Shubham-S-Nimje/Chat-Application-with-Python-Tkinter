# Chat-Application-with-Python-Tkinter

ChatApplication using Tkinter

Client/Server Application

Client is person who send and receive message
Server which receive message send by client and broadcast to all other clients
connected to server

Technology

1. socket module (networking app)
2. threading module (multithreading app)
3. tkinter (GUI)

Server is a program, which provide services

1. Maintain clinet connections
2. Receive messsage send by client and sending to other clients
